# October Daily Challenge 日程

> 占位模板，方便后续手动编辑社区／Discord 每日挑战列表。
> 已接入每日挑战日历，读取 [`daily-challenge-schedule-2026-10.json`](./daily-challenge-schedule-2026-10.json)，每日 **HKT 08:00** 切换。

## 标准化说明

> - `[Race]` 且无括号线路的条目保留活动名，`routeCode: null`、`race: true`。
> - `Marathon (R370)` / `R370` → `Marathon Shuttle (R370)`。
> - `Marathon (R148)` / `R148` → `Marathon Shuttle (R148)`。
> - 私人租用（PH）站序每日随机；已知站序写入 JSON 的 `privateHireStops` 字段。

## 私人租用（PH）站序
